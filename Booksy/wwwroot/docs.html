API Reference

All endpoints grouped by feature area. Click any group to expand.

Authentication Endpoints marked with require a JWT bearer token. Register via POST /api/Authentication/register, then login to receive your token. Pass it as Authorization: Bearer <token>.
Authentication
6 endpoints
POST /api/Authentication/register Create a new account
POST /api/Authentication/login Login & receive JWT token
POST /api/Authentication/confirm-email Confirm email with OTP
POST /api/Authentication/reset-password Reset account password
POST /api/Authentication/resend-otp Resend OTP code
POST /api/Authentication/refresh-token Refresh JWT access token
Books
7 endpoints
GET /api/Books List books (paginated, filterable)
GET /api/Books/{id} Get book by ID
GET /api/Books/slug/{slug} Get book by slug
POST /api/Books Create book
PUT /api/Books/{id} Update book
DELETE /api/Books/{id} Soft-delete book
POST /api/Books/{id}/image Upload book cover image
Cart & Checkout
7 endpoints
GET /api/Carts Get current user's cart
POST /api/Carts/items Add item to cart
PUT /api/Carts/items/{id} Update cart item quantity
DELETE /api/Carts/items/{id} Remove cart item
DELETE /api/Carts Clear cart
POST /api/Checkouts Create Stripe checkout session
POST /api/Checkouts/webhook Stripe webhook handler
Orders
5 endpoints
GET /api/Orders List user orders
GET /api/Orders/{id} Get order details
POST /api/Orders Place an order
PATCH /api/Orders/{id}/status Update order status (admin)
DELETE /api/Orders/{id} Cancel order
Reviews
5 endpoints
GET /api/Reviews List reviews
GET /api/Reviews/{id} Get review
POST /api/Reviews Submit a review
PUT /api/Reviews/{id} Update review status
DELETE /api/Reviews/{id} Delete review
Statistics & Reports
6 endpoints
GET /api/Statistics/dashboard Dashboard summary stats
GET /api/Statistics/books Book-level statistics
GET /api/Statistics/users User activity statistics
GET /api/Reports/top-books?limit=10 Top-selling books
GET /api/Reports/monthly-revenue?months=12 Monthly revenue data
GET /api/Reports/sales?startDate=&endDate= Detailed sales report
